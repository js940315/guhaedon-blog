## 0. 한 줄 요약

네이버 블로그 10개 → 워드프레스 허브 1개 → 스포크 2개로 내려보내는 유입 구조를
만들고, **복붙 직전까지 자동화**했다. 네이버는 API 발행을 막으므로 그게 자동화 한계다.

```
네이버 스포크 10개 ──(전부 같은 허브 URL, 글당 2회)──▶ 메인허브(광고1·CTA3)
                                                        ├─▶ 1차(광고2)
                                                        └─▶ 2차(광고2)
```

수익 관점의 근거: 스포크로 직접 보내면 광고 2개만 보고 끝난다.
허브를 거치면 1 → 3개를 본다. 백링크도 허브 한 곳에 뭉쳐야 신생 도메인에서 신호가 선다.

## 1. ⭐ 이번에 실측으로 확정한 사실 (추측 아님, 전부 확인함)

| # | 사실 | 확인 방법 |
|---|---|---|
| 1 | 네이버는 **대량 붙여넣기한 URL을 텍스트 링크로만** 만든다. 썸네일 카드가 되려면 **URL 단독 입력 + 엔터**가 필요하다 | 사용자가 실제 글에서 재현 |
| 2 | 네이버 링크 카드는 og:image **우측을 약 5% 잘라낸다** (`savemoney119` → `savemoney11`) | 카드 스크린샷 |
| 3 | 카드는 [이미지 + og:title + og:description + 도메인] 4조각. **description은 뒤가 `…`로 잘린다** | 카드 스크린샷 (117자였음) |
| 4 | `➜ ➔ → »` 는 Noto Sans KR 에 글리프가 없어 **두부(□)로 깨진다** | 렌더 결과 |
| 5 | 썸네일 요소를 고정 y좌표로 배치하면 폰트 자동확대 시 **아래 요소를 파고든다** (실제 -12px 겹침) | 글자 bbox 측정 |
| 6 | 네이비 배경 위 빨강(#FF5A46)은 **폰 크기(1/3.3)로 줄이면 배경에 먹힌다.** 노랑(#FFD600)이 확실히 낫다 | 360px 축소 비교 |
| 7 | Rank Math `rank_math_facebook_title/description` 은 **REST로 실제 반영된다** (SEO용과 분리 가능) | 라이브 패치 후 메타 재확인 |
| 8 | 그날 허브 세트에는 **FAQ가 14개**(hub 4·t1 5·t2 5) 있고, 이게 세부키워드 후보 그 자체다 | `_set_20260809.py` |

**미확인 (추정으로 남겨둔 것)**
- 네이버 카드가 **1:1로 통짜 크롭하는 화면이 있는지**. 관측된 건 우측 5%뿐이라
  `thumbnail_gen.OG_HOOK_W = 760` 으로 잡아뒀다. 1:1 크롭이 확인되면 **640으로 줄인다.**
- og:description이 **정확히 몇 글자에서 잘리는지**. 지금 100자로 맞춰뒀다.

## 2. 이번 세션에 바꾼 파일 (wp_lite, 전부 커밋 안 됨)

| 파일 | 무엇이 바뀌었나 |
|---|---|
| `thumbnail_gen.py` | **`make_og_thumbnail()` 신규 추가.** 기존 `make_thumbnail()` 은 안 건드림 |
| `set_publisher.py` | 세트 발행이 `make_og_thumbnail()` 사용 + `og_title`/`og_desc` 전달 |
| `wp_publisher.py` | `patch_rank_math_meta_v2()` 에 `og_title`/`og_description` 인자 추가 |
| `COWORK_TASK_PROMPT.md` | v4 썸네일 규칙 + `og_title`/`og_desc` 작성 규칙 추가 |

### `make_og_thumbnail()` 설계 근거 (임의로 되돌리지 말 것)
- 카드가 제목·설명을 이미 보여주므로 **이미지는 제목을 반복하지 않는다.**
  "눌러야 하는 이유" 하나만 담당한다.
- **측정 기반 배치**: 모든 블록 높이를 먼저 재고, 간격(46/30/54px)을 더해
  세로 중앙 배치. 넘치면 후크 폰트를 156→78 로 줄여가며 맞춘다. 고정 y좌표 금지.
- 강조색 노랑 고정. 워터마크 없음(카드 하단에 도메인이 이미 나온다).
- 계층별 후크 전략이 다르다:

| 페이지 | 전략 | 예 |
|---|---|---|
| 메인허브 | 자기대입 질문 | 나도 / 대상일까? |
| 1차 | 손실 + 마감 | 안 쓰면 / 3개월 뒤 소멸 |
| 2차 | 몰랐던 정보 | 5천원이 / 끝이 아니다 |

### 세트 cfg 에 새로 필요한 5개 필드
```python
"thumb_eyebrow": "462만명 유출",        # 12자 이내
"thumb_hook": ["나도", "대상일까?"],     # 한 줄 4~7자, 2줄째가 노랑
"thumb_cta": "가입 시기로 1분 확인",     # ▶ 는 자동. 화살표 직접 쓰지 말 것
"og_title": "따릉이 유출 462만명 나도 대상일까",   # 20자 내외, 쉼표 금지
"og_desc":  "가입한 적 있으면 대상일 수 있습니다. 문자를 못 받았어도 그렇습니다. ...",  # 앞 40자가 전부
```
없으면 기존 필드로 폴백되지만 **제목이 반복돼 효과가 크게 떨어진다.**

## 4. 남은 작업 (우선순위)

1. **[확인] 새 카드 렌더** — 허브 URL을 네이버에 다시 넣고 새 썸네일·새 설명으로 뜨는지.
   옛것이 뜨면 네이버 캐시. 잘림 폭을 보고 `OG_HOOK_W` 최종 확정.
2. **[확인] og:description 잘리는 글자 수** — 100자가 적정한지 판단.
3. **[미착수] 벤치마킹 블로그 구조 분석** — `m.blog.naver.com/andudtk12/2243717065xx` 5건.
   코워크에서는 그 도메인을 못 열었다. 클로드 코드에서 열 수 있으면 분석 후
   `HANDOFF_스포크_운영.md` 2절(제목 공식)·3절(본문 슬롯)에 반영한다.
4. **[미착수] 썸네일 배경 변주** — 10개 글에 같은 카드가 반복되면 3일차부터 눈이 지나친다.
5. **[미착수] 사진 배경 도입** — economy-blog 의 Pexels 라이브러리(`build_stock_library.py`)를
   가져올 수 있다. 키는 환경변수 `PEXELS_API_KEY` 등. 코드·커밋에 값 금지.
6. **[미착수] wp_lite 코드를 저장소로** — 지금 `thumbnail_gen.py` 등이 OneDrive에만 있어
   버전 관리가 안 된다. repo 로 옮기면 zip 왕복이 없어진다.

## 5. 절대 하지 말 것

- **애드센스 클릭 유도 금지.** 계정 정지 사유다. `hub_builder.py` 는 이미
  CTA 블록 앞뒤에 광고를 안 넣고, '광고' 라벨을 붙이고, min-height 로 레이아웃 밀림을
  막고 있다. 이 원칙을 건드리지 않는다. 목표는 클릭이 아니라 **노출 × 체류 × 페이지뷰**다.
- 네이버 글에 **외부 링크 3개 이상 금지.** 정확히 2회, 둘 다 메인허브.
- 워드프레스 본문을 네이버에 복붙 금지 — 중복 콘텐츠로 양쪽 다 죽는다.
- 단축 URL·리다이렉트 금지. 원본 주소 그대로.
- 지역명만 바꾼 복제글 금지. 표의 숫자와 주의사항은 실제로 달라야 한다.
- `_set_*.py` 에 없는 숫자·기한을 썸네일이나 og 문구에 지어 넣지 않는다.
